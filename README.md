# kafi.dev.bd — Portfolio

Static portfolio site (HTML, CSS, vanilla JS). No build step.

## Structure
- `index.html` – markup, SEO meta, JSON-LD
- `kafi.dev.bd.css` – styles
- `kafi.dev.bd.js` – interactions (menu, scroll-spy, reveal, counters, form)
- `images/` – assets (folder name is lowercase: Linux hosts are case-sensitive)
- `robots.txt`, `sitemap.xml`, `vercel.json` – SEO and hosting config

## Run locally
    npx serve .
